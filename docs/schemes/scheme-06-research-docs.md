> **方案代号**：Research & Docs  
> **适用场景**：技术选型、方案调研、知识库建设  
> **推荐指数**：⭐⭐⭐⭐  
> **所需 CLI**：Claude Code + Gemini CLI  
> **AI 员工总数**：4 个研究员  
> **预计效率提升**：400%–600%（多 AI 交叉验证）

## 一、方案概述

技术选型和方案调研需要多角度分析。本方案用 2 个 Claude 研究员和 2 个 Gemini 研究员从不同角度并行调研，利用不同 AI 模型的知识偏好实现交叉验证。

### 核心理念

```
你（技术总监）── 发起调研课题
  │
  ├── 🔬 Claude 研究员-1  →  深度技术分析（原理层）
  ├── 🔬 Claude 研究员-2  →  代码实践对比（实战层）
  ├── 🔬 Gemini 研究员-1  →  生态数据搜集（数据层）
  └── 🔬 Gemini 研究员-2  →  兼容性/迁移评估（风险层）
  │
  ▼
你 ← 汇总 4 份报告 → 交叉验证 → 选型决策 → 输出文档
```

### 为什么混用 Claude + Gemini？

- **Claude** 擅长：深度代码分析、架构推理、细粒度对比
- **Gemini** 擅长：信息检索、数据统计、生态概览
- 同一问题两个模型的答案不同 → **暴露盲区，提高决策质量**

## 四、调研场景详解

### 4.1 场景：前端状态管理选型

```
你（群聊 @All）:
"调研课题：Vue 3 项目状态管理方案选型

背景：
  - 中大型 Vue 3 + TypeScript 项目
  - 需要 SSR 支持（Nuxt 3）
  - 团队 5 人，前端经验参差不齐
  - 需要 DevTools 支持

候选方案：
  A. Pinia
  B. Zustand (Vue adapter)
  C. Jotai (Vue adapter)

各位分工：
  🔬 Claude研究员-1: 架构原理对比
    - 三个方案的内部实现原理
    - 响应式系统集成方式
    - TypeScript 支持深度
    
  🔬 Claude研究员-2: 实战代码对比
    - 用三个方案实现相同的购物车功能
    - 对比代码量、可读性、可维护性
    - 测试便利性对比
    
  🔬 Gemini研究员-1: 生态与社区数据
    - GitHub Stars、npm 周下载量趋势
    - Issue 响应速度、PR 合并频率
    - 相关文章/教程/插件数量
    - 主要使用者/公司
    
  🔬 Gemini研究员-2: 兼容性与迁移评估
    - Nuxt 3 SSR 兼容性
    - Vue DevTools 集成
    - 从 Vuex 迁移成本
    - 潜在 breaking changes 风险

输出格式：每人一份报告，包含结论和依据。"
```

### 4.2 场景：前端构建工具选型

```
你（群聊 @All）:
"调研课题：构建工具迁移方案评估

背景：当前项目使用 Webpack 5，考虑迁移到 Vite 或 Rspack

分工：
  @Claude研究员-1: Vite vs Rspack 编译原理对比
    - 热更新机制差异
    - 生产构建策略
    - 插件兼容性（特别是 webpack 插件）
    
  @Claude研究员-2: 迁移代码改造
    - webpack.config.js → vite.config.ts 配置映射
    - webpack.config.js → rspack.config.ts 配置映射
    - 常见迁移坑点和解决方案
    
  @Gemini研究员-1: 性能基准数据
    - 冷启动时间对比
    - 热更新速度对比
    - 生产构建时间对比
    - Bundle 大小对比
    
  @Gemini研究员-2: 企业采用状况
    - 大厂迁移案例
    - 稳定性反馈
    - 长期维护承诺"
```

## 五、交叉验证策略

### 5.1 如何发现分歧

4 份报告汇总后，重点寻找：

| 分歧类型 | 示例 | 处理方式 |
|---------|------|---------|
| 事实性分歧 | A 说支持 SSR，B 说不支持 | 追问具体版本 |
| 评价性分歧 | A 认为性能好，B 认为一般 | 要求给出基准数据 |
| 范围性分歧 | A 只看了核心功能，B 看了插件 | 统一评估范围 |
| 时效性分歧 | A 的数据是去年的 | 要求更新到最新 |

### 5.2 追问模板

```
你（群聊 @All）:
"各位报告已收到。发现以下分歧需要澄清：

1. 关于 Pinia 的 SSR 支持：
   Claude研究员 说完全支持
   Gemini研究员 说有已知问题
   → 请各自给出具体版本和 issue 链接

2. 关于 Zustand 的 Vue adapter 成熟度：
   Claude研究员 认为可用于生产
   Gemini研究员 认为还不够稳定
   → 请给出判断依据（下载量、issue 数、版本号）

请补充以上论据。"
```
