## 五、Prompt 模板库

### 5.1 Schema 设计

```
设计 {模块名} 的数据库 Schema。

业务需求：
{需求描述}

要求：
1. PostgreSQL DDL 语句
2. 主键使用 UUID
3. 必要的索引
4. 外键约束
5. 软删除支持（deleted_at）
6. 审计字段（created_at, updated_at）
7. 注释说明每个字段用途

同时输出：
- Prisma schema 格式
- TypeScript 类型定义
- 种子数据 SQL（5-10 条测试数据）
- ER 图（文本描述）
```

### 5.2 查询优化

```
分析以下 SQL 查询的性能，给出优化建议：

查询：{SQL}
表结构：{Schema}
数据量：{预估行数}

分析：
1. 执行计划分析
2. 缺失索引
3. 查询改写建议
4. 分页优化（大数据量场景）
```

### 5.3 迁移脚本

```
为以下 Schema 变更生成迁移脚本：

变更描述：{描述}
当前 Schema：{当前}
目标 Schema：{目标}

输出：
1. 前进迁移 SQL (up)
2. 回滚迁移 SQL (down)
3. 数据迁移 SQL（如需）
4. 注意事项和风险点
```

## 六、协作关系

```
上游：你（CEO）→ 业务需求 → 数据库设计师

下游：数据库设计师 → Schema 完成 → 后端开发（实现 API）
      数据库设计师 → 类型定义 → 类型工程师（统一类型）
```

---

## 七、微调建议

| 数据库 | 调整 |
|--------|------|
| PostgreSQL | 利用 JSONB、Array、CTE |
| MySQL | 注意 InnoDB 锁机制 |
| SQLite | 适合本地/嵌入式 |
| MongoDB | Schema 设计为文档结构 |
