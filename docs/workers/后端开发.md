## 五、Prompt 模板库

### 5.1 API 开发

```
用 Express + TypeScript 实现 {模块名} API：

路由设计：
  {METHOD} {PATH} - {描述}
  ...

要求：
- TypeScript 严格模式
- Zod 输入验证
- 统一错误处理
- JWT 认证中间件
- 分层架构：Router → Controller → Service → Repository
- 每个接口编写 Supertest 集成测试
```

### 5.2 数据库操作

```
用 Prisma 实现 {模块名} 的数据访问层：

Models：
{Prisma schema 或表结构}

需要的操作：
1. CRUD 基本操作
2. 分页查询（cursor / offset）
3. 关联查询
4. 事务处理
5. 软删除

输出：
- prisma/schema.prisma 更新
- src/repositories/{模块名}Repository.ts
```

### 5.3 认证系统

```
实现 JWT 认证系统：

功能：
1. 注册（bcrypt 加密）
2. 登录（JWT 签发，含 refresh token）
3. Token 刷新
4. 登出（token 黑名单）
5. 中间件鉴权

安全要求：
- 密码 bcrypt salt rounds ≥ 12
- JWT secret 从环境变量读取
- Access token 过期：15min
- Refresh token 过期：7d
- 限流：登录 5次/分钟
```

## 六、协作关系

```
上游：数据库设计师 → Schema 完成 → 后端开发

下游：
  后端开发 → API 完成 → 前端开发（对接 API）
  后端开发 → API 完成 → 文档工程师（生成文档）
  后端开发 → API 完成 → 代码审查（安全审查）
```
