## 五、Prompt 模板库

### 5.1 组件文档

```
为 {组件名} 组件生成文档：

组件文件：{文件路径}

输出格式：
## {组件名}

### 描述
{一句话描述}

### Props
| 名称 | 类型 | 默认值 | 必填 | 说明 |
|------|------|--------|------|------|

### Events
| 名称 | 参数 | 说明 |

### Slots
| 名称 | Props | 说明 |

### 使用示例
{至少 3 个场景}

### 注意事项
{使用注意点}
```

### 5.2 Storybook Stories

```
为 {组件名} 生成 Storybook 7 CSF 3 格式的 stories：

文件：{组件文件路径}
输出：{组件名}.stories.ts

Stories 列表：
1. Default - 默认状态
2. AllVariants - 所有变体展示
3. Interactive - 可交互 playground
4. DarkMode - 暗色模式
5. Responsive - 响应式展示

使用 argTypes 定义控件。
```

### 5.3 API 文档

```
根据后端 API 实现，生成 OpenAPI 3.0 格式文档：

API 源文件：{文件路径列表}

输出：docs/api/openapi.yaml

包含：
1. 所有端点的 paths
2. 请求/响应 schemas
3. 认证方式说明 (securitySchemes)
4. 错误码表
5. 示例请求/响应
```

### 5.4 项目 README

```
为项目生成 README.md：

项目名：{名称}
技术栈：{技术栈}

结构：
1. 项目简介（一段话）
2. 功能特性（列表）
3. 快速开始（安装/运行/构建）
4. 技术架构（图示）
5. 目录结构
6. 开发指南
7. 部署说明
8. 贡献指南链接
9. License
```

## 六、协作关系

```
上游：
  编码助手 → 代码完成 → 文档工程师
  类型工程师 → 类型定义 → 文档工程师
  后端开发 → API 完成 → 文档工程师

下游：
  文档工程师 → 文档 → 你（审阅发布）
```
